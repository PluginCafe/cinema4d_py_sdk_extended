# Rendering

Contains code examples covering rendering a BaseDocument via the Cinema 4D API.

| Script | Description |
| batch_render_post_process_2026_2.py | Demonstrates to manipulate the file outputs of a batch render post process once the rendering has finished. |
| batch_render_pre_process_2026_2.py | Demonstrates how to pre-process multiple documents before adding them to the batch renderer for rendering. |
| render_document_complex_2026_2.py | Demonstrates how to render a document with custom render settings, including progress and write hooks. |
| render_document_hardware_2026_2.py | Demonstrates how to render a document using the Hardware Preview render engine. |
| render_document_preroll_2026_2.py | Demonstrates how to render a document with a preroll frame range. |
| render_document_set_engine_2026_2.py | Demonstrates how to set a specific render engine for rendering a document. |
| render_document_simple_2026_2.py | Demonstrates how to render a document and save the output to disk. |
| render_document_tiles_2026_2.py | Demonstrates how to render a document split into tiles which can be composited back together to a full image. |
